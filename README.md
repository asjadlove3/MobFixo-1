# MobFixo — New Delhi (demo site)

Next.js 16 + Tailwind 4 + GSAP. Fully standalone: no external API calls, fonts are bundled via @fontsource.

## Run on localhost
```
npm install
npm run dev
```
Open http://localhost:3000 (Node 20.9+ required, 22 LTS recommended).

## Edit content
- Name, phone, email, address, offers, products: `site/content.ts`
- Colours: `site/site.ts` (theme) and `site/zones.ts`
- Logo: `site/components/Logo.tsx`

All contact details are dummy placeholders.
